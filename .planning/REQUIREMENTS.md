# 物证管理系统 v1 Requirements

## v1 Requirements (Phase 1)

### Authentication & Authorization

- [ ] **AUTH-01**: 用户可使用用户名/密码登录系统并保持会话（JWT Token）
- [ ] **AUTH-02**: 超级管理员可新增、编辑、禁用用户，设置密码策略
- [ ] **AUTH-03**: 支持多级用户模式（市级/区县单位数据隔离）
- [ ] **AUTH-04**: 用户按角色获取权限，权限标识格式：模块:实体:操作

### Role & Permission Management

- [ ] **ROLE-01**: 系统预设角色（超级管理员、物证管理员、办案民警、审核员/领导、审计员）
- [ ] **ROLE-02**: 支持自定义角色和精细化权限分配
- [ ] **ROLE-03**: 角色权限修改即时生效

### Organization & Data Isolation

- [ ] **ORG-01**: 单位管理（支持多级：市-区县）
- [ ] **ORG-02**: 用户归属单位，业务数据与本单位关联
- [ ] **ORG-03**: 同级单位之间数据隔离，上级可查看下级数据
- [ ] **ORG-04**: 基于@DataScope注解实现数据权限控制

### Audit & Logging

- [ ] **LOG-01**: 操作日志记录（用户ID、操作类型、操作时间、IP地址、操作详情）
- [ ] **LOG-02**: 操作日志不可删除、不可篡改
- [ ] **LOG-03**: 日志哈希校验（HMAC-SHA256）
- [ ] **LOG-04**: 审计员可查看日志、导出审计报告

### System Configuration

- [ ] **CONFIG-01**: 物证分类配置（普通/贵重/涉密/危险/易腐）
- [ ] **CONFIG-02**: 物证等级配置（一般/重要/核心）
- [ ] **CONFIG-03**: 保管期限配置
- [ ] **CONFIG-04**: 编号规则配置（一物一码规则）
- [ ] **CONFIG-05**: 单位配置
- [ ] **CONFIG-06**: 双人双锁开关配置（具体控制逻辑二期实现）
- [ ] **CONFIG-07**: 预警规则配置（到期提醒等）

### Evidence Core

- [ ] **EVI-01**: 物证唯一编码自动生成（一物一码）
- [ ] **EVI-02**: 物证信息录入（案件编号、名称、类型、等级、数量、单位等）
- [ ] **EVI-03**: 物证分类管理
- [ ] **EVI-04**: 物证等级管理
- [ ] **EVI-05**: 物证信息编辑与补充（受控修改，记录修改历史）
- [ ] **EVI-06**: 物证状态管理（在库/借出/送检/销毁/丢失/损毁）
- [ ] **EVI-07**: 物证照片管理（上传、查看）
- [ ] **EVI-08**: 物证查询（多条件精准查询）

### Evidence Check-in & Storage

- [ ] **STORE-01**: 现场物证接收（接收人、接收时间、交接清单）
- [ ] **STORE-02**: 入库单人核验（二期改为双人）
- [ ] **STORE-03**: 智能仓位分配建议
- [ ] **STORE-04**: 封签管理（唯一封签号生成、封签绑定、封签解绑）
- [ ] **STORE-05**: 制式入库单生成与电子签名
- [ ] **STORE-06**: 物证分区保管（仓位管理）

### Evidence Transfer & Checkout

- [ ] **TRANS-01**: 物证调用申请（申请理由、借出时间、预计归还时间）
- [ ] **TRANS-02**: 分级审批流程（按物证等级：一般/重要/核心不同审批级别）
- [ ] **TRANS-03**: 工作流引擎（支持统一模板+单位独立模板）
- [ ] **TRANS-04**: 物证出库核验（确认借证人、核验物证）
- [ ] **TRANS-05**: 物证归还管理（归还核验、逾期提醒）
- [ ] **TRANS-06**: 跨单位移交管理（多级模式下）

### Workflow Engine

- [ ] **WF-01**: 工作流定义管理（创建、编辑、启用/禁用模板）
- [ ] **WF-02**: 工作流节点配置（审批节点、处理人/角色、流转条件）
- [ ] **WF-03**: 统一工作流模板（市级统一使用）
- [ ] **WF-04**: 单位独立工作流模板（多级模式下区县可独立配置）
- [ ] **WF-05**: 工作流实例管理（发起、审批、流转历史）
- [ ] **WF-06**: 审批人指定（固定审批人、角色审批人、单位主管）
- [ ] **WF-07**: 审批意见记录
- [ ] **WF-08**: 审批超时提醒

### Dashboard & Reporting

- [ ] **DASH-01**: 领导督查Dashboard（入库量、出库量、库存量统计）
- [ ] **DASH-02**: 物证分类/状态/等级统计图表
- [ ] **DASH-03**: 预警统计展示

---

## v2 Requirements (Deferred)

- 双人双锁具体控制逻辑（入库、出库、销毁、盘点）
- 物证保管与监控（盘点、预警、状态锁定）
- 物证处置与销毁（退还、销毁、拍卖、上缴、移送）
- 报表导出（Excel/PDF）
- 硬件对接（RFID扫码枪、标签写印一体机）
- 移动端（警务通）
