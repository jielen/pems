  <name>Task 1: Create pems_config table and entity</name>
  <files>pems_backend/sql/pems_schema.sql</files>
  <action>
Create SQL migration file `pems_schema.sql` with these tables:

1. **pems_config table** (system configuration):
   - id BIGINT PRIMARY KEY AUTO_INCREMENT
   - param_key VARCHAR(100) NOT NULL UNIQUE (e.g., "evidence_type", "evidence_level", "numbering_rule", "dual_lock_enabled")
   - param_value VARCHAR(500)
   - param_type VARCHAR(50) (e.g., "string", "number", "boolean", "json")
   - remark VARCHAR(255)
   - create_time DATETIME
   - update_time DATETIME

   Pre-populate with CONFIG-01~07 defaults:
   - evidence_type: "1,2,3,4,5" (普通/贵重/涉密/危险/易腐)
   - evidence_level: "1,2,3" (一般/重要/核心)
   - retention_period: "{}" (JSON with type->days mapping)
   - numbering_rule: "YEAR|MONTH|SEQ|CHECK" format
   - dual_lock_enabled: "false"
   - alert_rules: "{}" (JSON)

2. **pems_audit_log table** (immutable audit log):
   - id BIGINT PRIMARY KEY AUTO_INCREMENT
   - evidence_id BIGINT (optional, NULL for system operations)
   - operation_type VARCHAR(50) NOT NULL
   - operator_id BIGINT NOT NULL
   - operator_name VARCHAR(50)
   - operator_badge VARCHAR(20) (警号)
   - operator_unit VARCHAR(100)
   - operate_time DATETIME NOT NULL
   - operator_ip VARCHAR(50)
   - detail TEXT (JSON operation details)
   - prev_hash VARCHAR(64) (previous log's hash for chain)
   - hash_value VARCHAR(64) (current HMAC-SHA256 hash)
   - create_time DATETIME
   - NO update_time, NO update_by (immutable)
   - NO delete method (cannot delete audit logs)

3. **sys_dept_extend table** (department extension):
   - dept_id BIGINT PRIMARY KEY (FK to sys_dept.dept_id)
   - unit_code VARCHAR(50) UNIQUE (e.g., "000", "000001", "000001001")
   - dept_level INT (1=city, 2=district, 3=station)
   - parent_unit_code VARCHAR(50)
   - sequence_num INT (3-digit sequence within parent)
   - create_time DATETIME
   - update_time DATETIME

Include SQL comments explaining the structure per 若依 framework convention.
